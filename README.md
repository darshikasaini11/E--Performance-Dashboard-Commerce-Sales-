📌 Project Overview

This project is a full-stack data science solution that transforms raw e-commerce transactional data into actionable business insights and predictive analytics.

It combines:

📊 Data Engineering
🤖 Machine Learning
📈 Business Intelligence
🌐 Interactive Web Dashboard
🎯 Problem Statement

E-commerce platforms generate large volumes of transactional data, but lack:

Unified data view
Predictive sales insights
Real-time business dashboards

👉 This project solves that by building an end-to-end analytics pipeline + ML forecasting system.

🧠 Key Features
🧹 Data cleaning & preprocessing pipeline
🔗 Multi-table data merging (orders, customers, products)
📊 Feature engineering for revenue insights
🤖 ML model for sales prediction (Random Forest Regressor)
📉 Model evaluation using MAE
🌐 Interactive Streamlit dashboard
📦 Power BI-ready dataset generation


🏗️ System Architecture
Raw Data (CSV)
      ↓
Data Cleaning (Pandas)
      ↓
Feature Engineering
      ↓
ML Model Training (Random Forest)
      ↓
Predictions Dataset
      ↓
Streamlit Dashboard + Power BI Export
